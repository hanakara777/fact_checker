# fact_checker
Are you sure what your friend is telling you its factually correct?

Model is trained on two datasets that have either true statements that are and sound real, and false statements. Model was trained to recognise the linguistic pattern and classifies statement as likely true or likely false. 

Built as a foundation for a future agent that will research claims across the web and scientific literature.

*important: this model is pattern-recognition model, not knowledge based. It predicts whether a statement sounds as true or false. Next step is an agent that will research web. for actual fact verification.*

model used for training : meta-llama/Llama-3.1-8B-Instruct
